# Roadmap

Fecha de decisión: 10 de septiembre de 2026.

## Estado actual

HornoExacto V1 es un experimento acotado. La utilidad técnica se puede probar; la demanda, la recurrencia y la monetización todavía no están demostradas. La V1 no contiene anuncios, afiliación, pagos, cuentas ni servicios externos.

## Publicación y observación

1. Publicar y comprobar las tres herramientas, rutas, almacenamiento, exportación e importación.
2. Configurar Search Console y solicitar portada más las tres herramientas solo si existe acceso real a esas acciones.
3. Mantener GA4 desactivado hasta disponer de un flujo real y consentimiento comprobado.
4. Revisar durante 8–12 semanas descubrimiento, consultas pertinentes, errores y tareas abandonadas. Comparar después periodos de 28 días, sin interpretar cero impresiones como prueba de demanda nula mientras haya problemas de descubrimiento o indexación.
5. Si es posible, observar cinco tareas reales y registrar finalización, errores y esfuerzo frente al método habitual. Cuatro de cinco finalizaciones es una regla interna de usabilidad, no validación de mercado.

## Expansión de HornoExacto

Coste y lista de compra permanecen en V1.5. Solo se construirá una nueva herramienta cuando consultas repetidas durante al menos dos periodos de 28 días muestren una tarea distinta, o usuarios reales pidan repetidamente el mismo flujo. Antes se comprobará que la solución no duplica una página existente.

Prefermentos, masa madre, planificador de horneadas, masa de pizza especializada y moldes irregulares requieren fórmulas, límites y validación propios. No se añadirán para aumentar artificialmente el número de páginas.

Si tras unos seis meses apenas existen consultas pertinentes y tampoco uso recurrente, se congela la expansión y se revisa la propuesta.

## Puertas para los proyectos siguientes

### TejeConMedida — sin comenzar

Antes de crear código o repositorio hacen falta:

- un caso concreto y recurrente resuelto mejor que las alternativas;
- evidencia fechada de al menos tres usuarios independientes del público objetivo que describan ese problema;
- comparación del mismo caso con al menos dos herramientas actuales, indicando qué queda sin resolver.

Tres testimonios limitan la inversión, pero no validan estadísticamente el mercado. Terminar HornoExacto no activa este proyecto.

### ImprimeMedido — sin comenzar

Además de cerrar los proyectos anteriores hacen falta:

- al menos tres usuarios independientes con la misma tarea de medidas o etiquetas mal resuelta;
- comparación reproducible con GridPrint y Avery, o con las alternativas pertinentes;
- un plan viable para contrastar físicamente el PDF en una impresora disponible.

Si las alternativas resuelven el caso sin fricción significativa observada, el proyecto permanece en reserva.

## Coste de oportunidad y mantenimiento

La estimación concreta de esta V1 antes de publicar fue de 5–9 horas de ejecución técnica para construcción, contenido, QA, repositorio y despliegue, más el tiempo externo de indexación y observación que no puede garantizarse. No es un presupuesto comercial ni incluye reclutamiento, entrevistas, soporte continuado o adquisición de tráfico.

Cada revisión debe registrar tiempo real y compararlo con mejorar CosteCoche o CuántoMaterial. El mantenimiento incluye revisar navegadores, enlaces externos, claridad de fórmulas y versiones de GitHub Actions.
