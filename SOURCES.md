## Fórmulas y plataforma

- [King Arthur Baking: Baker's Percentage](https://www.kingarthurbaking.com/pro/reference/bakers-percentage): convención de harina total igual a 100 %. HornoExacto implementa las fórmulas con código y textos propios.
- [GitHub Docs: What is GitHub Pages?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages): modelo de alojamiento estático.
- [GitHub Docs: GitHub Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits): límites que deben revisarse antes de una futura explotación comercial.
- Las áreas de círculo, cuadrado y rectángulo son geometría elemental. La fórmula de adaptación divide volumen ocupado de destino entre volumen ocupado de origen.

## SEO, datos y privacidad

- [Google Search Central: Ask Google to recrawl your URLs](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl): solicitudes de rastreo, cuotas y límites.
- [Google: Create and submit a robots.txt file](https://developers.google.com/crawling/docs/robots-txt/create-robots-txt): ubicación del archivo en la raíz del host.
- [Google: Software app structured data](https://developers.google.com/search/docs/appearance/structured-data/software-app): referencia para `WebApplication`.
- [AEPD: Guía sobre el uso de las cookies](https://www.aepd.es/guias/guia-cookies.pdf): base para mantener analítica desactivada hasta implementar consentimiento válido.
